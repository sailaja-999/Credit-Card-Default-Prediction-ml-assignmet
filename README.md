# Credit-Card-Default-Prediction-ml-assignmet# Loan Default Prediction Using Machine Learning

## Problem Statement

Financial institutions face significant risks due to loan defaults. The objective of this project is to predict whether a credit card customer will default on their payment in the following month based on demographic information, credit history, bill amounts, and repayment behavior.

Five machine learning classification algorithms are implemented and compared:

1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbors
4. Naive Bayes
5. Random Forest

The models are evaluated using:

- Accuracy
- AUC Score
- Precision
- Recall
- F1 Score
- MCC Score
